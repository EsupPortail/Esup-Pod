# Optional transcription dependencies for Esup-Pod live streaming.
#
# Install this file in addition to requirements.txt if you want to enable
# live transcription. Two engines are supported:
#
#   - Vosk  : local, offline speech recognition (recommended for on-premise)
#   - Whisper: OpenAI's model (requires openai-whisper or faster-whisper)
#
# Install one of:
#   pip install -r requirements-transcription.txt          # Vosk only
#   pip install faster-whisper                             # Whisper alternative
#
# See CONFIGURATION.md for the LIVE_VOSK_MODEL and USE_LIVE_TRANSCRIPTION settings.
